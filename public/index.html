DATA HANDLING

Data handling.

This independent project uses a VATSIM CID and historical ATC records only to calculate quarterly totals. It does not need your password.

There is no login and no account database. The server does not store usernames, passwords, or cookies.

This project is designed around California privacy principles, including data minimisation, purpose limitation, transparency, and reasonable security practices. It does not sell personal information or use it for targeted advertising.

POLICY NOTES

Scope and accuracy.

Results are estimates and may be incomplete or inaccurate. They are not an official VATSIM compliance decision.

Current scope includes broad Division totals and the initial VATUSA ARTCC mapping. It does not fully evaluate every local roster, visiting-controller rule, rating rule, or activity exception.

Use the current official VATSIM, Division, and ARTCC guidance for any final determination.
